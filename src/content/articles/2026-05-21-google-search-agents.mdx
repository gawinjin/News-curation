## TL;DR

Google is adding agents to Search. AI Mode now uses Gemini 3.5 Flash, and Google is previewing background information agents, agentic booking, mini apps built inside Search, and optional personal context from apps like Gmail and Photos.

## What's New

Google says AI Mode has passed one billion monthly users. At I/O, the company made Gemini 3.5 Flash the default model in AI Mode worldwide and introduced a larger AI-powered Search box that accepts text, images, files, videos, and Chrome tabs.

The bigger shift is Search agents. Information agents will monitor the web and fresh data for a specific question, then send synthesized updates. Google gives examples like apartment hunting or tracking product drops. These start with Google AI Pro and Ultra subscribers this summer.

Search is also getting agentic booking for local experiences and services, generative UI for custom visual answers, and mini apps that can continue a task over time. Personal Intelligence is expanding too, with optional connections to Gmail, Google Photos, and soon Calendar.

## Why It Matters

Search used to be a place where you asked once, clicked links, and left. The new model is closer to delegation: tell Search what you are trying to track, compare, book, or build, and it keeps working around that goal.

That is useful for repetitive research, but it changes how you should evaluate results. An agentic search answer should show sources, preserve constraints, and make it easy to stop or edit the task. Without those controls, automation can become invisible drift.

<PracticalGuide timeToTry="15 min" prerequisites={["Google Search with AI Mode access", "One recurring search task"]}>

1. Pick one recurring search task, such as tracking apartment listings, comparing laptop prices, or monitoring a grant deadline.
2. Write the task as constraints, not keywords. Include budget, location, deadline, must-haves, and deal breakers.
3. Run it in AI Mode and ask for a table with source links and open questions.
4. Check two source links manually before trusting the summary.
5. If background agents become available in your account, start with this same task and set a narrow update rule, such as "only tell me when all must-haves match."
