## TL;DR

ChatGPT is rolling out a new memory system designed to keep personal context fresher across conversations. It also adds a memory summary users can inspect and correct. The update starts with Plus and Pro users in the United States before expanding to more plans and countries.

## What's New

OpenAI calls the underlying approach "dreaming": a background process that synthesizes useful context from past conversations instead of relying only on individual saved notes. The new architecture is intended to carry forward useful details, follow preferences, and update memories as circumstances change.

The visible improvement is a memory summary. Users can review what ChatGPT knows, type corrections, highlight specific text to change, or ask it not to mention a detail again. OpenAI says memory controls remain available in settings, and Temporary Chat does not use or create memories.

Rollout is limited at first. Plus and Pro users in the United States receive the new system first, with additional countries and Free and Go users planned for later.

## Why It Matters

Better memory can make repeated planning and long-running projects less tedious, but it also increases the importance of reviewing stored context. Old locations, finished projects, and sensitive details can lead to irrelevant or unwanted personalization.

Treat the memory summary like any profile assembled about you: inspect it, correct it, and remove information you do not want reused. OpenAI notes that fully deleting a detail may require deleting it from every place it appears, including relevant chats, files, and connected apps.

<PracticalGuide timeToTry="10 min" prerequisites={["A ChatGPT account with memory available"]}>

1. Open https://chatgpt.com/ and go to Settings, then Personalization or Memory.
2. Open the memory summary or Manage memories page and check when it was last updated.
3. Find one outdated or overly broad detail and correct it using the available edit controls.
4. Start a new chat and ask, "What do you remember about my current projects?" to check the result.
5. Use Temporary Chat for the next conversation if you do not want that conversation to use or create memory.
