## TL;DR

SpaceXAI released Grok 4.5 for coding, multi-step agent work, and document tasks. It is available in Grok Build, Cursor, and the API, with limited free use advertised in Grok Build and Cursor at launch.

## What's New

Grok 4.5 is SpaceXAI's new flagship work model. The company positions it for software engineering, science, math, and office tasks rather than casual chat alone.

The release is the default model in Grok Build and is available in Cursor on all plans. Developers can also use it through SpaceXAI's API at a listed price of $2 per million input tokens and $6 per million output tokens.

SpaceXAI reports 80 generated tokens per second and strong results on coding tests, but those are provider-selected measurements. The model is not yet available in the European Union, where the company expects access later in July.

## Why It Matters

The most interesting promise is speed on tasks that usually need repeated back-and-forth: fixing a small program, organizing a spreadsheet, or turning notes into a usable document. A faster model only helps if its first result is accurate enough to reduce corrections.

Use the launch trial on a task where you know what good looks like. That gives you a personal comparison against your current tool without paying for a long experiment or trusting benchmark rankings.

<PracticalGuide timeToTry="15 min" prerequisites={["A Grok Build or Cursor account","A small task with a result you can inspect"]}>

1. Open [Grok Build](https://x.ai/cli) or Cursor and select Grok 4.5 if it appears in the model picker.
2. Choose a small, reversible task: fix one visible bug, clean one table, or outline a five-slide presentation.
3. State the expected result and ask the model to show how it checked its work.
4. Inspect the output yourself, including formulas, links, and any changed files.
5. Compare the time and number of corrections with the model you normally use before moving a larger task over.
