## TL;DR

ChatGPT now has a Lockdown Mode for people who handle sensitive information. It reduces the chance that a malicious prompt hidden in a web page, file, or connected source can make ChatGPT send private data outward. The tradeoff is that some web, agent, file-download, and connector behavior may be limited.

## What's New

OpenAI's help page says Lockdown Mode is rolling out to eligible personal accounts, including Free, Go, Plus, and Pro, plus self-serve ChatGPT Business accounts. It is an optional advanced security setting, not a default mode for everyone.

The setting works by limiting outbound network requests and other external-service capabilities that could be used for data exfiltration. OpenAI says it can substantially reduce prompt-injection risk, but it does not guarantee that every data leak or prompt-injection effect is impossible.

The earlier OpenAI announcement framed Lockdown Mode as a deterministic restriction rather than another model judgment. Simon Willison highlighted the same point: the useful move is cutting off the path that lets sensitive data leave the system.

## Why It Matters

The risky combination is private data, untrusted content, and a tool that can send information somewhere else. Many modern AI workflows combine all three: a chatbot reads files, browses pages, and uses connectors in one conversation.

If you use ChatGPT for legal, financial, medical, business, or personal material, Lockdown Mode is worth checking. It may make some tasks less convenient, but the safer default is often the right tradeoff for sensitive work.

<PracticalGuide timeToTry="5 min" prerequisites={["A ChatGPT account", "A reason to handle sensitive information in ChatGPT"]}>

1. Open https://chatgpt.com/ and go to Settings.
2. Open Security or the workspace setting area where Lockdown Mode is listed.
3. Turn on Lockdown Mode if it is available for your account.
4. Start a new chat and try a low-risk task that normally uses web browsing or a connector.
5. Confirm which features are limited, then leave the setting on for chats involving sensitive files, connected apps, or private notes.
