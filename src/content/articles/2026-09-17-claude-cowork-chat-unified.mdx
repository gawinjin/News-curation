## TL;DR

Claude is combining chat and Cowork, letting people ask a quick question or assign a longer task from the same conversation. The change is reaching Pro and Max accounts gradually, so some users will still see separate modes for now.

## What's New

The unified interface removes the choice between regular chat and Cowork before starting. Claude decides which tools a request needs, while existing projects, connectors, skills, artifacts, and Cowork tasks carry over.

Anthropic is introducing the change in stages for Pro and Max users on the web, desktop, and mobile apps. If Chat and Cowork still appear as separate choices, that account has not moved yet. There is no setting to force the update, and Free and Team plans are due to follow later.

Claude Docs and Claude Slides are also new in beta on paid plans, and Claude Design can now work inside conversations. Claude asks for approval before taking actions by default.

## Why It Matters

The change makes the first step simpler: describe the result you want instead of deciding which Claude product fits the job. A short answer can stay short, while a report, spreadsheet, or presentation can become a longer task in the same place.

The staged release matters when following tutorials or helping a colleague. Two people on the same paid plan may see different controls, so check the message box before following instructions. Start with fictional information and the default permission setting to learn how Claude plans and revises a task without exposing work files.

<PracticalGuide timeToTry="10 min" prerequisites={["A Claude Pro or Max account with Cowork available; the unified interface may not have reached your account","A browser and three fictional notes; no file or app permissions are needed"]}>

1. Open [claude.ai](https://claude.ai) and sign in. If the message box still offers **Chat** and **Cowork**, select **Cowork**. If those options are gone, start a new conversation; that means the unified interface has reached your account.
2. Check the permission setting in the message box. Choose **Manual** (or **Ask before acting** in the older Cowork interface) so you can review any action request.
3. Paste these fictional notes: 'Meeting moved to Tuesday. Ada will draft an agenda. Budget is undecided.' Ask: 'Make a one-page recap with decisions, open questions, and next actions. Use only these notes.' Submit the task; do not connect a folder or app.
4. Inspect Claude's approach and result. Check that it leaves the budget open and assigns the agenda to Ada. If it invents a budget or owner, ask it to remove that claim and compare the revision with the notes.
5. If your account offers Claude Docs, open the recap there and try one direct text edit. If Docs is absent, keep the plain recap in the conversation.

</PracticalGuide>
