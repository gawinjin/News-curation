## TL;DR

Anthropic released Claude Sonnet 5 across all plans. It is now the default model for Free and Pro users, available to paid team tiers, and positioned as a cheaper everyday model for agentic work, coding, and tool use.

## What's New

Sonnet 5 narrows the gap between Anthropic's Sonnet and Opus families. Anthropic says it improves reasoning, tool use, coding, knowledge work, and agentic performance compared with Sonnet 4.6.

The model is available in Claude chat, Claude Code, and the Claude Platform. Developers can call it as `claude-sonnet-5`.

Anthropic also gives Sonnet 5 introductory API pricing through August 31, 2026, then raises it to the standard listed price. That matters for anyone moving repeated agent workflows onto the model.

## Why It Matters

Sonnet is the model many people actually touch first. A better default model can matter more than a headline flagship if it improves the everyday experience for planning, writing, research, coding, and small automations.

The practical question is whether Sonnet 5 follows through better on multi-step tasks. Test it with something you can verify, not with a vague prompt where any fluent answer looks good.

<PracticalGuide timeToTry="15 min" prerequisites={["A Claude account","One task with a checkable result"]}>

1. Open Claude and check the model picker or default model label for Sonnet 5.
2. Choose one bounded task that normally takes 20 to 40 minutes, such as summarizing a document or planning a small project.
3. Ask Sonnet 5 to make a plan first, then approve only the first step.
4. Compare its result against your source material or checklist instead of trusting the completion.
5. If you use Claude Code or the API, check pricing and effort settings before moving a repeated workflow to Sonnet 5.

</PracticalGuide>
