## TL;DR

OpenAI is adding more provenance signals to AI images. It is using C2PA metadata, Google DeepMind's SynthID watermarking, and a public verification preview to help people check whether an image came from ChatGPT, Codex, or the OpenAI API.

## What's New

OpenAI says it is now a C2PA Conforming Generator Product. C2PA is an open standard that attaches signed metadata to media, so tools and platforms can read information about where an image came from and how it was created or edited.

The company is also adding SynthID watermarking to images generated through ChatGPT, Codex, or the OpenAI API. That matters because metadata can be stripped when images are resized, downloaded, screenshotted, or moved between platforms. A watermark gives a second signal.

OpenAI is previewing a public verification tool that checks uploaded images for provenance signals, including Content Credentials and SynthID. At launch, it is limited to content generated by OpenAI tools and does not make a definitive claim when no signal is found.

## Why It Matters

This is not a perfect AI detector. OpenAI is careful about that, and users should be too. The useful part is narrower: when provenance survives, people get a receipt that can help answer where an image came from.

For journalists, teachers, marketplaces, teams, and normal group chats, that is still useful. The right habit is to treat provenance as one signal alongside source, context, and common sense, not as a magic truth machine.

<PracticalGuide timeToTry="10 min" prerequisites={["An image you are allowed to upload", "A browser"]}>

1. Open OpenAI's provenance article and use the linked verification tool if it is available in your region.
2. Upload a harmless test image that you are allowed to share.
3. Read the result carefully. A positive signal can show OpenAI provenance; a missing signal does not prove the image is human-made.
4. If you use AI images at work, save the original generated file before posting or resizing it.
5. When sharing an AI image publicly, keep a note of the tool, date, prompt purpose, and whether the file still has provenance metadata.
