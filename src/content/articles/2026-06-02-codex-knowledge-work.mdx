## TL;DR

OpenAI says Codex is increasingly used for ordinary knowledge work, not only software development. People are using it to research topics, analyze data, create reports and spreadsheets, and build small tools. A safe first test is to give it a folder of non-sensitive material and request one reviewable deliverable.

## What's New

OpenAI published a report on June 2 describing how Codex usage is spreading beyond developers. According to the company, knowledge workers now represent about one fifth of Codex users and are growing faster than its developer audience.

The common outputs are familiar office work: reports, spreadsheets, presentations, contracts, research, and data analysis. Codex's existing app model supports this by working inside a selected local workspace, showing progress, and producing files that the user can inspect.

This does not make every office task a good fit for an agent. The strongest starting points are bounded jobs with clear source material and an output you can verify, such as turning meeting notes into a decision brief or summarizing a small CSV.

## Why It Matters

The important shift is from asking a chatbot for advice to asking an agent to create a concrete artifact. That can save time, but it also changes the review burden: users need to check the source files, calculations, citations, and final output before relying on it.

Start with low-risk material and a narrow deliverable. A useful agent workflow should leave you with something easier to review than the pile of inputs you began with.

<PracticalGuide timeToTry="15 min" prerequisites={["Access to the Codex desktop app", "A folder containing non-sensitive notes or sample data"]}>

1. Create a new folder containing two or three non-sensitive notes or a small sample CSV.
2. Open that folder as a workspace in the Codex desktop app.
3. Ask Codex to create a one-page Markdown brief that identifies key facts, open questions, and the source file for each fact.
4. Review the generated file against the originals and correct any unsupported statement.
5. Ask Codex to revise the brief using your corrections, then keep the final file only if every important claim is traceable.

</PracticalGuide>
