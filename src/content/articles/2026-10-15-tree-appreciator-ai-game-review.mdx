## TL;DR

Simon Willison asked Claude Opus 5.5 Max, through the standard Claude iPhone chat, to build a spot-the-difference game using two 3D trees. After 3 hours and 7 minutes, Claude returned a playable browser game that anyone can test without an account.

## What's New

Willison's prompt asked for a fun, visually appealing Three.js game centered on comparing two generated trees. He used chat mode in the standard iPhone app, not Claude Code, and Claude worked for 3 hours and 7 minutes before delivering the playable result.

Tree Appreciator synchronizes rotation and zoom across each pair. It also includes music, animation, hints, scoring, achievements, and a herbarium that records completed pairs. A public build record links the original prompt, model, generated commit, and shared Claude transcript, making the finished game easier to compare with the request that started it.

The live game supports touch, mouse, and keyboard controls and saves progress in the current browser. It requires WebGL, and its small visual differences may be difficult for people with low vision or color-vision limitations. Starting a new walk clears the herbarium and field-guide progress.

## Why It Matters

This is an inspectable example of what one long mobile chat request produced, not a general test of Claude's reliability or game-design ability. Instead of judging the result from a description, readers can play it and compare the original request with the build record.

That playtest shifts attention from whether AI generated code to whether the finished interaction works. Clear controls, understandable feedback, useful hints, saved progress, and accessibility all matter more to a player than how the game was made.

<PracticalGuide timeToTry="15 min" prerequisites={["A current browser with WebGL enabled","No account, Claude subscription, coding, upload, or personal information","Ability to distinguish small visual differences; keyboard controls exist, but the game may still be difficult with low vision or color-vision limitations"]}>

1. Open Tree Appreciator, confirm that two 3D trees load, read the tutorial, and select Got it. If a WebGL warning appears, try an updated supported browser; do not install an unfamiliar extension or weaken browser security.
2. Play the first pair without Hint: drag to rotate both trees, pinch or scroll to zoom, and select one visible difference. Confirm that the game marks it and advances the noticed counter; a miss should reduce the score slightly.
3. Find the remaining differences. If stuck for two minutes, select Hint once and observe how it guides you and changes the leaf rating. Finish the pair and confirm that a herbarium summary shows time and misses.
4. Select Next pair and complete three pairs to reach the Connoisseur's round. Answer its visual question and note whether the feedback makes the judgment understandable rather than merely surprising.
5. Open Field Guide, switch to Herbarium, and confirm completed pairs were saved. Reload the page and check that the entries remain. Do not select Start a new walk unless you intend to erase that progress.
6. Write a three-line verdict: one clear control, one moment that created attention or fun, and one friction or accessibility problem. Judge the finished interaction rather than the novelty of AI generating it.
