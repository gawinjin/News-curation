## TL;DR

OpenAI has rebuilt its desktop app around Chat, Work, and Codex. Work can plan and carry out longer projects across files and connected apps, while the same app adds a browser, scheduled tasks, and shareable Sites. Desktop access is rolling out broadly; web and mobile access begins with paid plans.

## What's New

Work is a new project mode powered by GPT-5.6. You describe an outcome, review its proposed approach, and let it work across approved files and apps. It can produce documents, spreadsheets, presentations, and simple shareable websites rather than stopping at a chat response.

The updated macOS and Windows app now combines Chat, Work, and Codex. It also includes a built-in browser and Scheduled Tasks for recurring work. OpenAI is folding the separate Codex app into this unified app and replacing the standalone Atlas browser over time.

OpenAI says the desktop app is available globally across plans. Work on web and mobile is starting with paid users, so the exact controls you see can depend on your plan and rollout stage.

## Why It Matters

The useful change is continuity. A research or planning task can stay in one workspace while the agent reads approved material, creates several related outputs, and returns them for review. That removes some of the manual copying between chat, files, and productivity apps.

It also raises the cost of a vague instruction. Before granting access, define the deliverables, source boundary, and actions that require confirmation. Review the plan and every external action instead of treating an agent run as an automatic approval.

<PracticalGuide timeToTry="15 min" prerequisites={["The latest ChatGPT desktop app for macOS or Windows","A small project with source files you can safely upload"]}>

1. Update the ChatGPT desktop app and look for the Work mode beside Chat and Codex.
2. Choose a low-risk task, such as turning three non-sensitive notes into a one-page summary and a five-slide outline.
3. State the exact outputs, tell Work to use only the attached files, and require confirmation before any external action.
4. Review the proposed plan, remove unnecessary permissions, and start the task.
5. Check every factual claim against the source files, then compare the finished outputs with your requested format before sharing them.
