## TL;DR

Anthropic released Claude Fable 5, its most capable broadly available Claude model, on June 9. It is the public version of the new Mythos class: strong enough for long-running agent work, but guarded so sensitive cyber, biology, chemistry, and model-extraction requests can fall back to Opus 4.8.

## What's New

Fable 5 is Anthropic's first widely available Mythos-class model. Claude Mythos 5 uses the same underlying model, but is limited to Project Glasswing participants and other approved users because some safeguards are lifted for trusted security work.

The model is aimed at ambitious, long-running work: large coding projects, multi-stage knowledge work, visual review of charts and files, and agent sessions that plan, check progress, and revise their own work. Anthropic's docs list a 1 million token context window, 128,000 maximum output tokens, always-on adaptive thinking, and pricing of $10 per million input tokens and $50 per million output tokens.

The catch is policy and safety behavior. Fable 5 requires 30-day data retention for safety monitoring and is not available under zero data retention. Anthropic says requests flagged by its safeguards can be rerouted to Opus 4.8, and its early data shows most Fable sessions do not trigger a fallback.

## Why It Matters

For normal users, Fable 5 is not the model to use for every quick rewrite or everyday question. It is a premium option for work where better long-range planning and self-checking might save real time: reviewing a complicated plan, untangling a large document set, or comparing a difficult implementation strategy.

The important decision is whether the task deserves the cost and retention tradeoff. If the work contains private customer data, regulated business information, or sensitive research, check the data policy before pasting anything into Fable.

1. Open https://claude.ai/ and check whether Claude Fable 5 appears in your model picker.
2. Choose a hard but non-sensitive task, such as reviewing a project plan, comparing two product ideas, or finding weak assumptions in a public document.
3. Run the task once with Claude Opus 4.8 and save the answer.
4. Start a new chat, select Claude Fable 5, and run the same prompt.
5. Compare the two answers for specificity, useful caveats, self-checking, and whether Claude reports a model fallback.
6. Use Fable for private or business-sensitive work only after you are comfortable with Anthropic's 30-day retention requirement.
